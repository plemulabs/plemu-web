Plemu browser player components

EmulatorJS 4.2.3 is GPL-3.0. Its license is LICENSE; complete unminified frontend modules are under data/src/. Plemu uses the source-module loader so the readable, modified code is the executed code. The stable player disables external update queries, browser storage/cache and multiplayer; storage guards are evaluated before storage getters for an opaque-origin sandbox. Other upstream notices remain in place.

Selected WebAssembly cores: gambatte (Game Boy/Color), FCEUmm (NES), mGBA (GBA). Exact bundled licenses are under notices/. Core artifacts are taken from the official 4.2.3 release. Core source repositories are listed in data/cores/cores.json. These are downloaded compiled artifacts; a corresponding-source/toolchain reproducibility review remains a public-distribution release gate. Do not infer binary/source equivalence from a repository URL.
