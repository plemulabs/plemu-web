# Plemu brand assets

The primary mark is `plemu-pixel-face.png`. The header uses `plemu-wordmark-lime.png`; `plemu-wordmark-alt.png` provides the alternate background. These PNG assets are supplied Plemu artwork.

`plemu-mark.svg` and `plemu-logo.png` are legacy variants retained for decorative uses and fallback imagery. The interface crops the supplied wordmark with CSS.
