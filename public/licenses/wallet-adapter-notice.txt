Plemu adapts the React wallet provider to make selected-wallet storage conditional on user choice, keep mobile authorization in memory and require versioned terms acknowledgment before new wallet authorization/signing calls. Public SDK interfaces and upstream lifecycle handling are retained. The wallet UI stylesheet omits the upstream Google Fonts import because the font is self-hosted.
